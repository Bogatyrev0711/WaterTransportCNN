# WaterTransportCNN
 1. Описание проекта

Данный проект представляет собой систему классификации изображений морских судов на основе сверточной нейронной сети (Convolutional Neural Network, CNN).

Цель проекта — разработать модель машинного обучения, способную определять тип судна по изображению.

Проект реализован в рамках изучения дисциплины «Нейронные сети и глубокое обучение».

 2. Цель работы
Изучить основы глубокого обучения
Освоить работу со сверточными нейронными сетями (CNN)
Реализовать модель классификации изображений
Провести обучение и тестирование модели
Получить практический результат работы нейросети
 3. Классы классификации

Модель обучена распознавать 6 типов морских судов:

Контейнеровоз (Container Ship)
Эсминец (Destroyer)
Рыболовное судно (Fishing Boat)
Нефтяной танкер (Oil Tanker)
Пассажирское судно (Passenger Ship)
Подводная лодка (Submarine)

 5. Описание датасета

Датасет состоит из изображений морских судов, распределённых по 6 классам.

Каждый класс представлен отдельной папкой с изображениями соответствующего типа судна.

 6. Используемые технологии
Python 3.x
TensorFlow / Keras
NumPy
Matplotlib
PyCharm / Jupyter Notebook
 7. Архитектура модели

Используется сверточная нейронная сеть (CNN), состоящая из:

3 сверточных слоя (Conv2D)
слоёв MaxPooling
слоя Flatten
полносвязного слоя Dense (128 нейронов)
выходного слоя Softmax (6 классов)
 8. Параметры обучения
Размер изображения: 128 × 128 пикселей
Batch size: 32
Количество эпох: 10
Функция потерь: Sparse Categorical Crossentropy
Оптимизатор: Adam
Разделение данных: 80% обучение / 20% валидация
 9. Результаты обучения

Во время обучения модель показывает улучшение точности (accuracy) и снижение функции потерь (loss).

Также строятся графики:

Accuracy (точность модели)
Loss (ошибка модели)

Модель демонстрирует хорошую способность к классификации изображений судов.

 10. Использование модели

Для предсказания используется отдельный скрипт predict.py.

Пример работы:

Результат:

Класс судна
Уверенность модели (probability)
