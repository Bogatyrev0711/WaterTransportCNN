**# WaterTransportCNN**
 1. Описание проекта
Данный проект представляет собой систему классификации изображений морских судов на основе сверточной нейронной сети (Convolutional Neural Network, CNN).
Цель проекта — разработать модель машинного обучения, способную определять тип судна по изображению.
Проект реализован в рамках изучения дисциплины «Нейронные сети и глубокое обучение».

 2. Цель работы
Изучить основы глубокого обучения
Освоить работу со сверточными нейронными сетями (CNN)
Реализовать модель классификации изображений
Провести обучение и тестирование модели
Получить практический результат работы нейросети

 3. Классы классификации
Модель обучена распознавать 6 типов морских судов:
Контейнеровоз (Container Ship)
Эсминец (Destroyer)
Рыболовное судно (Fishing Boat)
Нефтяной танкер (Oil Tanker)
Пассажирское судно (Passenger Ship)
Подводная лодка (Submarine)

 5. Описание датасета
Датасет состоит из изображений морских судов, распределённых по 6 классам.
Каждый класс представлен отдельной папкой с изображениями соответствующего типа судна.

 6. Используемые технологии
Python 3.x
TensorFlow / Keras
NumPy
Matplotlib
PyCharm / Jupyter Notebook
 
 7. Архитектура модели
Используется сверточная нейронная сеть (CNN), состоящая из:
3 сверточных слоя (Conv2D)
слоёв MaxPooling
слоя Flatten
полносвязного слоя Dense (128 нейронов)
выходного слоя Softmax (6 классов)

 8. Параметры обучения
Размер изображения: 128 × 128 пикселей
Batch size: 32
Количество эпох: 10
Функция потерь: Sparse Categorical Crossentropy
Оптимизатор: Adam
Разделение данных: 80% обучение / 20% валидация

 9. Результаты обучения
Во время обучения модель показывает улучшение точности (accuracy) и снижение функции потерь (loss).
Также строятся графики:
Accuracy (точность модели)
Loss (ошибка модели)
Модель демонстрирует хорошую способность к классификации изображений судов.

**Как происходит обучение модели**
Обучение сверточной нейронной сети (CNN) в данном проекте проходит в несколько этапов.

 1. Подготовка данных
Сначала изображения из датасета загружаются с помощью TensorFlow.
Каждое изображение:
изменяется до размера 128×128 пикселей
нормализуется (значения пикселей переводятся из диапазона 0–255 в диапазон 0–1)
автоматически получает метку класса (например: контейнеровоз, эсминец и т.д.)

 2. Разделение данных
Все изображения делятся на две части:
обучающая выборка (train) — используется для обучения модели (80%)
валидационная выборка (validation) — используется для проверки качества обучения (20%)

 3. Процесс обучения
Во время обучения происходит следующее:
 Шаг 1 — прямой проход (forward pass)
Изображение проходит через нейронную сеть:
сверточные слои выделяют признаки (формы, контуры, текстуры корабля)
полносвязные слои анализируют эти признаки
модель делает предсказание класса
 Шаг 2 — сравнение с правильным ответом
Предсказанный класс сравнивается с реальным классом из датасета.
 Шаг 3 — вычисление ошибки (loss)
Вычисляется функция потерь (loss), которая показывает:
насколько сильно модель ошиблась
 Шаг 4 — обратное распространение ошибки (backpropagation)
Ошибка передаётся обратно по сети, и:
корректируются веса нейронов
модель постепенно “учится” распознавать изображения лучше

 4. Повторение процесса
Этот процесс повторяется много раз (эпохи):
в проекте используется 10 эпох
после каждой эпохи модель становится точнее

 5. Контроль качества
После каждой эпохи выводятся:
accuracy (точность)
loss (ошибка)
val_accuracy (точность на новых данных)
val_loss (ошибка на новых данных)
Это позволяет понять:
насколько хорошо обучается модель
нет ли переобучения

 Итог
В результате многократного повторения этих шагов модель:
выделяет характерные признаки каждого типа судна
учится различать классы
становится способной классифицировать новые изображения
